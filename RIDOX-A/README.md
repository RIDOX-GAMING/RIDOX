# RIDOX-A — اپلیکیشن اندروید (راهنما)

⚠️ همون‌طور که در نسخه ویندوز گفتم: من اینجا به اینترنت دسترسی ندارم، پس نمی‌تونم خودم APK رو کامپایل کنم و مستقیم بدم دستت (کامپایل اندروید نیاز به دانلود Android SDK و Gradle داره). اما این پروژه یک اپ اندروید کاملاً واقعی و بومی (native، بدون Capacitor/Cordova) هست که با یک GitHub Action آماده، خودش به‌صورت خودکار روی سرورهای گیت‌هاب APK رو می‌سازه و به Release ضمیمه می‌کنه.

## روش پیشنهادی: ساخت خودکار با GitHub Actions

1. این پوشه از قبل داخل ریپازیتوری اصلی RIDOX هست — نیازی به کار اضافه نیست، فقط کل ریپو رو push کن.
2. یک تگ نسخه‌ی اندروید بساز و push کن (پیشوند `android-v` داره تا با تگ‌های نسخه‌ی ویندوز، که با `v` شروع می‌شن، قاطی نشه):
   ```
   git tag android-v1.0.0
   git push origin android-v1.0.0
   ```
3. تب **Actions** رو باز کن — workflow "Build & Release RIDOX APK" خودش اجرا می‌شه (چند دقیقه طول می‌کشه چون کل Android SDK رو دانلود می‌کنه).
4. بعد از اتمام، تب **Releases** رو ببین — فایل `RIDOX.apk` ضمیمه شده و آماده‌ی دانلود و نصب روی گوشیه.

می‌تونی به‌جای زدن تگ، از تب Actions به‌صورت دستی هم workflow رو اجرا کنی و APK رو از بخش Artifacts بگیری.

## روش دوم: ساخت روی سیستم خودت

با Android Studio یا Android SDK + JDK 17 نصب‌شده:
```
gradle assembleDebug
```
فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نصب روی گوشی
چون این APK از گیت‌هاب می‌گیری نه از Google Play، باید موقع نصب گزینه‌ی «نصب از منابع ناشناس» رو برای مرورگر یا فایل‌منیجرت فعال کنی.

## این اپ چیکار می‌کنه
- **ورود لوکال بدون سرور**: بار اول یک نام‌کاربری/رمز می‌سازی که فقط روی همون گوشی ذخیره می‌شه (`localStorage` داخل WebView). دفعات بعد مستقیم وارد اپ می‌شی، بدون نیاز به ثبت‌نام یا لاگین دوباره.
- **بخش V2Ray**: سه سرویس (نقره‌ای، طلایی پلاس، کاستوم) با قیمت و تخفیف مشخص. زدن دکمه‌ی خرید یک کد ۵ رقمی رندوم می‌سازه و می‌گه به @RIDOX_Neonguard در تلگرام ارسال بشه.
- **بخش وضعیت**: سه سرور با پینگ نمایشی که هر ۴ ثانیه به‌صورت رندوم در بازه‌ی مشخص‌شده تغییر می‌کنه؛ سرور فرانسه به‌صورت ثابت «خاموش» نشون داده می‌شه.
- **بخش اکانت من**: نام‌کاربری، وضعیت اشتراک (غیرفعال)، تعداد سفارش‌ها، و امکان وارد کردن کد معرف — همه لوکال و بدون سرور.

## ساختار پروژه
یک پروژه‌ی Android بومی با یک Activity ساده که یک WebView رو نمایش می‌ده و کل اپ (`app/src/main/assets/index.html`) داخلش اجرا می‌شه. بدون هیچ وابستگی بیرونی (بدون Capacitor، بدون کتابخونه‌ی اضافه)، سبک و قابل build با گریدل خالص.
