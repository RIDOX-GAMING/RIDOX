## 📱 RIDOX Android
اپلیکیشن اندروید (بومی، بدون سرور) داخل پوشه‌ی [`RIDOX-A`](./RIDOX-A) قرار داره.

برای ساخت خودکار APK از طریق GitHub Actions، یک تگ با پیشوند `android-v` بزن:
```bash
git tag android-v1.0.0
git push origin android-v1.0.0
```
بعد از اتمام workflow "Build & Release RIDOX APK"، فایل `RIDOX.apk` در تب Releases قرار می‌گیره.

جزئیات کامل‌تر داخل [`RIDOX-A/README.md`](./RIDOX-A/README.md).
